# Разработка

- `main.py` связывает интерфейс PyQt5 и Windows-команды, `collector.py` отвечает за проверку входных данных и ZIP-архив.
- `design*.py` и `ui/*.ui` описывают одни формы. При изменении текстов сохраняйте их согласованность.
- Сохраняйте один ZIP на LDAP без перезаписи. При ошибке удаляйте только новый частичный архив и не показывайте успех.
- Корпоративные адреса, персональные данные, логи и готовые EXE в репозиторий не добавляйте.
- Зависимости зафиксированы в `uv.lock`. Проверки: `uv run --locked ruff check .`, `uv run --locked ruff format --check .`, `uv run --locked mypy`, `uv run --locked pytest -W error`.
- Тесты изолированы от реального USD, сетевых папок и пользовательских логов. Windows EXE собирайте только на Windows командой из README.
