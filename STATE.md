# Состояние

Реализованы выбор папок через параметры запуска, проверка восьмизначного LDAP, ZIP без перезаписи и удаление частичного архива при ошибке. Входные папки проверяются до закрытия USD; ссылки на файлы за пределами источника пропускаются.

Локальные тесты проверяют архивирование на временных файлах и обработку ошибок. Для подтверждения всей цепочки нужны Windows с установленным Unified Service Desk и доступная папка назначения. Сборка EXE и работа с реальным USD на Windows не подтверждены.

Архивирование выполняется синхронно. При большом объёме логов окно может временно не отвечать; повторное сохранение блокируется до завершения.
